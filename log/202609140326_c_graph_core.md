## Key decisions

- **No templates.** `createFunction<AddFunction>` → `dressi_create_add`.
  `GetActiveADEngine` → process-global `dressi_active_ad()` set by
  `dressi_ad_create`.
- **C has no exceptions.** Missing engine / full pool / NULL args return
  NULL (ASSUMPTION; C++ `operator+` threw).
- **dressi_mul is element-wise** (paper A.5 bwd `gy * other`).
  `dressi_matmul` is not written. FLOAT `{1,1}` is the A.7 path.
- **SumPixelWise is not a new Function kind.** One contrib is identity
  (this-repo `SumContribs`); two or more fold with `dressi_add`.
- **Appendix typo:** paper `if (!gy)` → this-repo `if (!gx)`.
- **Pool:** `DRESSI_POOL_CAP 64` fixed arrays (ASSUMPTION; paper uses heap
  objects). `DRESSI_MAX_XS=4`, `DRESSI_MAX_USERS=8`.
- **`host_val` / `has_const`:** paper Variable has no payload; stored so
  the A.7 test can eval `1 * other` without CpuImage.
